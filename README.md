NotariaExpress es una aplicacion movil para una notaria. 
La aplicación inicia con una pantalla de inicio de sesión y perfil de usuario que almacena datos personales como RUT, teléfono, correo y ciudad mediante persistencia local de datos, evitando que el usuario deba reingresarlos en solicitudes posteriores. Al ingresar, la pantalla principal recibe al usuario con un saludo personalizado y despliega de inmediato la tarjeta correspondiente al trámite activo. Además, dispone de un menú para solicitar servicios notariales como poderes especiales o declaraciones juradas, permitiendo seleccionar la sucursal de preferencia y visualizar los requisitos necesarios de inmediato.
El sistema de seguimiento incorpora una barra de progreso que indica en tiempo real cada etapa del trámite, desde la recepción de la documentación por parte de la notaría hasta la generación del documento final firmado y listo para descarga. Asimismo, la plataforma cuenta con la sección Mis Documentos, la cual actúa como una carpeta digital para almacenar y previsualizar solicitudes finalizadas en formato PDF, e incluye un buscador de sucursales que provee mapas y vías de contacto directo como teléfono y correo electrónico.

Desde la perspectiva técnica y de diseño, la interfaz visual y los flujos de navegación fueron prototipados previamente en Figma. El desarrollo está construido en Android Studio sobre Kotlin siguiendo el patrón de arquitectura MVVM para organizar las responsabilidades en las capas model, repository, viewmodel y uii. La interfaz gráfica se implementó íntegramente con Jetpack Compose
